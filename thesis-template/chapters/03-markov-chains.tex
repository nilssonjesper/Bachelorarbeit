\section{Discrete-Time Markov Chains}\label{sec:DTMCs}
In this section, we will introduce definitions and theorems for Markov Chains. The notation and contents of this section are mostly based on \cite{Bibel}, \cite{Computing_EVTs_Stationary_Distr_in_MCs_Mertens}, and \cite{Semantics_Model-Checking_omega-Regular}.

\begin{definition}[DTMC]\label{def:DTMCs}
    A discrete-time Markov chain (DTMC) is a tuple $\MC = (S^\MC, \PF^\MC,\iota_{init}^\MC)$, where
    \begin{enumerate}[label=(\roman*)]
        \item $S$ is a countable, nonempty set of states,
        \item $\PF: S \times S \rightarrow [0,1]$ is the \textit{transition probability function}, with $\sum_{s'\in S}\PF(s,s') = 1$ for all states $s \in S$, and
        \item $\iota_{init}: S \rightarrow [0,1]$ is the \textit{initial distribution}, such that $\sum_{s\in S}\iota_{init}(s)=1$.
    \end{enumerate}
\end{definition}
Whenever the DTMC $\MC$ is evident from the context, we omit the superscript $\MC$ from $S^\MC$, $\PF^\MC$, and $\iota_{init}^\MC$.
We assume in this thesis, that the DTMCs are \textit{finite}, i.e., that the set of states $S$ is \textit{finite}. We sometimes refer to these finite DTMCs, as \textit{finite-state DTMCs}. We call a state $s\in S$ is called \textit{initial} if it satisfies $\iota_{init}(s) > 0$. Furthermore, we assume an arbitrary but fixed linear order $\prec$ on the set $S$, such that the states $s\in S$ can be indexed. Thus, $s_i \prec s_j$ if $s_i,s_j \in S$ and $i < j$. This allows us, for example, to denote the $i$-th entry of the initial distribution as $\iota_{init}(s_i)$, when viewing $\iota_{init}$ as a column vector.
Due to the conditions (i) and (ii) provided in \Cref{def:DTMCs}, the transition probability function $\PF$ and the initial distribution $\iota_{init}$ are discrete probability distributions, see \Cref{def:discrete_probability_distribution}.

\emph{\textbf{Paths and Probability Space.}}
To reason about the probabilistic behavior of a DTMC $\MC$, we define its probability space, in which the outcomes correspond to the infinite paths of $\MC$.

To this end, we fix a DTMC $\MC = (S,\PF,\iota_{init})$ for the rest of this section.

\begin{definition}[Path of a DTMC]
    An \textit{infinite path} $\pi$ in a DTMC $\MC$ is a sequence $\pi = (s_0, s_1, \dots$) of states with $s_0,s_1,\dots \in S$, such that $\PF(\pi[k],\pi[k+1]) > 0$. A \textit{finite path} is a finite prefix of an \textit{infinite path}.
\end{definition}

We use the notation $\pi[k]\in S$ to denote the $k$-th element of the path $\pi$ for all $k\in \NN_0$, i.e. $\pi[k] = s_k$.

Notice, that for any path $\pi$ a given state $\pi[k]$, which is visited in step $k\in \NN$, is always followed by one of its direct succesors, i.e., $\pi[k+1]\in N(\pi[k])$.
Furthermore, we define the length $|\pi|$ of a finite path $\pi = (s_0,\dots,s_k) \in Paths_{fin}^\MC$ to be equal to $k$, which we denote as $|\pi| = k$. As an infinite path is infinite in lenght, we define $\pi \in \Path$ to be $|\pi| = \infty$.
We denote the last state of a finite path $\pi \in Paths^{\MC}_{fin}$ as $last(\pi)$, i.e., if $|\pi| = n$, then $last(\pi) = \pi[n]$.
The sets of all infinite and finite sets are denoted as $\Path$ and $Paths_{fin}^\MC$, respectively.

Further, we construct the \textit{probability space} of a DTMC as follows. The events correspond to sets of infinite paths that can be expressed as countable unions and intersections of cylinder sets, i.e., sets containing all possible continuations of finite paths in $\MC$.

First, we define the \textit{until} operator ($\until$), see \cite{Bibel}.
\begin{definition}[Until Operator]\label{def:constrained_reachability_probabilities}
    Let $R,T \subseteq S^{\MC}$ be two sets of states of a DTMC $\MC$. For these two sets, we define the \textit{until} operator as
    \[R\until T = \{\pi \in \Path\mid\exists k\in \NN: \pi[k]\in T\land \forall i <k: \pi [i]\in R\} \ .\]

    Futhermore, the \textit{step-bounded until} operator is defined as
    \[R\until^{=k} T = \{\pi \in \Path \mid \pi[k]\in T\land \forall i <k: \pi [i]\in R\} \ .\]

\end{definition}
Intuitively, the set $R\until T$ contains all paths that only visit states in $R$, until a state in $T$ is visited.

Using the \textit{until} operator, we can introduce the \textit{eventually} operator ($\lozenge$).

\begin{definition}[Eventually Operator]
    Let $T\subseteq S$ be a set of states of a DTMC $\MC$. Then we define the \textit{eventually} operator as $\lozenge T = S \until T$.
    
    Consequently, we define the \textit{step-bounded eventually} operator as $\lozenge^{=k} T = S \until^{=k} T$.
\end{definition}
In other words, $\lozenge T$ contains all paths $\pi \in Paths^\MC_{fin}$ that visit at least one $t\in T$ at some point, i.e., there exists at least one $k \in \NN$ with $k \leq |\pi|$, such that $\pi[k] = t$.

With the \textit{eventually} operator, we can define the \textit{reachability probability}.
\begin{definition}[Reachability Probability]
    The reachability probability of a set $T \subseteq S^{\MC}$ in a DTMC $\MC$ is given by $Pr(\lozenge T)$.
\end{definition}

\emph{\textbf{Strongly Connected Components.}} We can partition the state set of a DTMC as shown in the following definition.

\begin{definition}[(Bottom) Strongly Connected Component]\label{def:(B)SCC}
    A non-empty set of states $C \subseteq S^{\MC}$ of a DTMC $\MC$ is \textit{strongly connected} if and only if for every pair of states $s,t\in S$, there exists a path $\pi \in \Path$, such that $\pi[0]=s$ and $\pi[k]$ for some $k\in \NN$.
    If $C$ is strongly connected and no proper subset of $C$, i.e. $C' \subset C$, is strongly connected, then $C$ is called a \textit{strongly connected component} (SCC).
    
    Furthermore, an SCC $C$ is called a \textit{bottom strongly connected component} (BSCC) if there exists no $k\in \NN$ and no path $(\pi[0], \dots, \pi[k],\dots) \in \Path$ such that $\pi[0]\in C$ and $\pi[k] \notin C$.
\end{definition}
In other words, once a state of a BSCC $C$ is entered, $C$ cannot be left again. % Notice, that any grouping 

Using BSCCs, we can define \textit{acyclic} DTMCs.
\begin{definition}[Acyclic DTMC]\label{def:acyclic_DTMC}
    A DTMC $\MC$ is called \textit{acyclic} if and only if each SCC is either a BSSC or a singleton set $\{s\}$ with $\PF(s,s) = 0$
\end{definition}

\emph{\textbf{Recurrent and Transient States.}} Using the \textit{recurrence probability} $Pr_s^\MC(\cCircle\lozenge s)$, we can partition the state set into \textit{recurrent} and \textit{transient} states.

\begin{definition}[Recurrent and Transient States]\label{def:transient_and_recurrent_states}
    For a given DTMC $\MC$ and state $s \in S$, $s$ is called \textit{recurrent} if and only if $Pr_s(\cCircle \lozenge s)=1$. All states that are not \textit{recurrent} are called \textit{transient}.
\end{definition}
In other words, a state is \textit{recurrent} precisely, when we are guaranteed to reach it from all of its direct successors, meaning once we reach a \textit{recurrent} state, we are bound to return to it. Using this definition, we can split the states $S$ of a DTMC into two sets with $S_{tr}$ containing all of the transient states and $S_{re}$ containing all of the recurrent states. 
Notice, that \textit{recurrent} states are precisely the states contained in a BSCC.
For convenience, we additionally define the set of \textit{initial} states $S^\MC_{in} = \{s \mid \iota^\MC_{init}(s) > 0\}$. Furthermore, we define the set of \textit{transient initial} states $\Strin \subseteq S_{in}$ with $\Strin = S_{in}\cap S_{tr}$. 

Moreover, the event $\lozenge S_{re}$, i.e., to reach any recurrent state, holds \textit{almost surely} in any DTMC.

\begin{theorem}[Limit Behaviour]
    For any DTMC $\MC$, set of recurrent states $S_{re}$, and any state $s\in S$, it holds that $\lim_{k\rightarrow\infty}Pr_s(\lozenge^{=k} S_{re})=1$.
\end{theorem}
Intuitively, the probability of reaching a recurrent state after $k$ steps, starting in $s$, tends towards 1 as $k$ tends towards infinity.

Lastly, we define \textit{absorbing} states.
\begin{definition}[Absorbing state]
    A states $s$ of a DTMC $\MC$ is refered to as an \textit{absorbing state} if and only if $\PF^{\MC}(s,s) = 1$.
\end{definition}
This means, once the model enters an \textit{absorbing} state, it cannot leave it. Notice, that \textit{absorbing} states are a special type of \textit{recurrent} states, as the only direct successor of an \textit{absorbing} state $s\in S$ is $s$ itself and therefore trivially $Pr_s(\lozenge s)=1$. Thus, we are guaranteed to return to a given \textit{absorbing} state after one step.

\begin{definition}[Markov Descision Process (MDP)]\label{def:MDP}\cite{Bibel}\todo{größtenteils übernommen}
    A \textit{Markov Decision Process} (MDP) is a tuple $\MDP = (S,Act,A,\PF,\iota_{init})$, where
    \begin{enumerate}[label=(\roman*)]
        \item $S$ is a countable set of states
        \item Act is a set of actions
        \item $A(s)\subseteq Act$ denotes the applicable actions for all states $s\in S$ 
        \item $\PF: S\times Act\times S \rightarrow [0,1]$ is the transition probability function such that $\sum_{s'\in S}\PF(s,\alpha, s') = 1$ for all $s\in S$ and $\alpha\in A(s)$
        \item $\iota_{init}: S \rightarrow [0,1]$ is the initial distribution such that $\sum_{s\in S}\iota_{init}(s)=1$
    \end{enumerate}
\end{definition}

\begin{definition}[Canonical Form]\label{def:canonical_form}
    For a DTMC $\MC$, its transition matrix $\tT$ is said to be in canonical form if and only if
    \[\tT = \begin{bmatrix}
        Q & R\\
        0 & S
    \end{bmatrix}\]
    where 
    \begin{enumerate}[label=(\roman*)]
        \item $Q = (\PF(s,t))_{s,t\in S_{tr}}$ contains the transition probabilities between the transient states
        \item $R = (\PF(s,t))_{s\in S_{tr},t\in S_{re}}$ contains the transition probabilities between transient and recurrent state pairs
        \item $S = (\PF(s,t))_{s,t\in S_{re}}$ contains the transition probabilities between the recurrent states
    \end{enumerate}
\end{definition}

Intuitively, the notion of EVTs describes how often we expect the model to be in a given state. To formally introduce EVTs, we fix a DTMC $\MC = (S,\PF,\iota_{init})$ and start by introducing \textit{visiting times} along paths.
\begin{definition}[Visiting Times of Infinite Paths]\label{def:visiting_times_of_infinite_paths}
    The function $vt_s:\Path \rightarrow \RR$ describes the \textit{visiting time} of a state $s\in S$ along infinite paths in $\MC$, where for $\pi\in \Path$
    \[vt_s(\pi)=\sum_{k=0}^{\infty}\llbracket \pi[k]=s \rrbracket\ .\]
    Similarly, the function $vt_T:\Path \rightarrow \RR$ descsribes the \textit{visiting time} of a set of states $T\subseteq S$ along infinite paths in $\MC$, where for $\pi \in \Path$
    \[vt_T(\pi)=\sum_{k=0}^{\infty}\llbracket \pi[k]\in T \rrbracket\ .\]
\end{definition}
As proven in \cite{Computing_EVTs_Stationary_Distr_in_MCs_Mertens}, the Lebesgue integral of the non-negative function $vt_s$ is well-defined for all states $s\in S^\MC$. Using this result, we can shortly prove the same for $vt_T$.
\begin{proof}
    Using \cref{def:visiting_times_of_infinite_paths},
    \begin{align}
        vt_T(\pi)
        & = \sum_{k=0}^{\infty}\llbracket \pi[k]\in T \rrbracket \notag \\
        & = \sum_{k=0}^{\infty}\sum_{t\in T}\llbracket \pi[k] = t \rrbracket \notag \\
        & = \sum_{t\in T}vt_t(\pi)\ .\notag
    \end{align}
    Thus, the Lebesgue integral of the non-negative function $vt_T$ is well-defined for all sets of states $T\subseteq S$.
\end{proof}

With this function, we can now define the EVT of a state $s$ as the expected value of $vt_s$ over all possible paths.


\begin{definition}[Expected Visiting Times in DTMCs]\label{def:EVTs_in_DTMCs}
    For a state $s\in S$, the \textit{expected visiting time} of $s$ is characterized as
    \[\Exp^{\MC}[vt_s]=\int_{\pi\in\Path}vt_s(\pi)dPr^{\MC}(\pi)\ .\]
    Additionally, we denote the \textit{expected visiting time} that is obtained by fixing a certain state $t\in S$ as the only initial state as $\Exp^\MC_t[vt_s]$. It is defined as
    \[\Exp^{\MC}_t[vt_s]=\int_{\pi\in\Path}vt_s(\pi)dPr_t^{\MC}(\pi)\ .\]
    Lastly, for a set of states $T\subseteq S$ the \textit{expected visiting time} of $T$ is characterized as
    \[\Exp^{\MC}[vt_T]=\sum_{t\in T}\Exp[vt_t]\ .\]
    % Moreover, \[\Exp^{\MC}[vt_s] = \]
    
    % \[ \Exp^{\MC}[vt_s]=\int_{s'\in S} \iota_{init}(s')\underbrace{\int_{\pi\in\Path\land \pi[0]=s'}vt_s(\pi)dPr^{\MC}(\pi)}_{=: \Exp_s'[vt_s]}.\]
\end{definition}
Because the probability measure of paths $\pi$, see definition \Cref{def:prob_space_of_DTMC}, is defined as a product containing the factor $\iota_{init}(\pi[0])$, it is nonzero only for paths that begin in a state $s$ with $\iota_{init}(s)>0$. Thus, the value $\Exp^\MC[vt_s]$ gives the number of times the state $s$ is expected to be visited from all paths in $\MC$ that start in one of the initial states. Whenever the DTMC $\MC$ is evident from the context, we will omit the superscript $\MC$ from $\Exp^\MC[vt_s]$, $\Exp_t^\MC[vt_s]$, and $\Exp^{\MC}[vt_T]$.

We shortly prove the third equation of \Cref{def:EVTs_in_DTMCs}.
\begin{proof}
    \begin{align}
        \Exp[vt_T] 
        & = \int_{\pi\in\Path}vt_T(\pi)dPr^{\MC}(\pi) \notag \\
        & = \int_{\pi\in\Path}\sum_{t\in T}vt_t(\pi)dPr^{\MC}(\pi) & \text{ (using \Cref{def:visiting_times_of_infinite_paths})} \notag \\
        & = \sum_{t\in T}\int_{\pi\in\Path}vt_t(\pi)dPr^{\MC}(\pi) \notag \\
        & = \sum_{t\in T}\Exp[vt_t] \ . & \text{ (using \Cref{def:EVTs_in_DTMCs})} \notag
    \end{align}
\end{proof}

Using the aforementioned partition of the set of states $S$ into transient and recurrent states, see \Cref{def:transient_and_recurrent_states}, we can already give a characterization for the latter.

\begin{lemma}[EVTs of Recurrent States]\label{lem:EVTs_of_recurrent_states}
    For all recurrent states $s\in S_{re}$, it holds that
    \[\Exp[vt_s] = 
    \begin{cases*}
        \infty & if s is reachable,\\
        0 & else.
    \end{cases*}\]
\end{lemma}
For a proof of this lemma, see \cite{Computing_EVTs_Stationary_Distr_in_MCs_Mertens}.

For this, we will first define the \textit{fundamental matrix} which was introduced by Kemeny and Snell \cite{KemenySnellBook}.

\begin{definition}[Fundamental Matrix]\label{def:fundamental_matrix}
    For a DTMC $\MC$ with the matrix $Q = (\PF^\MC(s,t))_{s,t\in S_{tr}}$ containing the transition probabilities between the transient states (defined in \Cref{def:canonical_form}), the \textit{fundamental matrix} $F$ is defined as,
    \[F = (I - Q)^{-1}\ .\]
\end{definition}
Kemeny and Snell show in \cite{KemenySnellBook} that $Q$ converges to the null matrix. Therefore, the Neumann series of $Q$ converges with $\sum^\infty_{k=0}Q^k = (\eye - Q)^{-1}$, see \Cref{def:neumann_series}, i.e., the fundamental matrix is well-defined.

Importantly for this thesis, Kemeny and Snell show in \cite{KemenySnellBook}, that the fundamental matrix gives for any two transient states $s,t\in S_{tr}$ the expected number of times $s$ is visited, when starting in $t$. To be more precise, $\Exp_t[vt_s] = (F)_{ts}$. From this equation, it intuitively follows that transient states are only visited a finite amount of times.

\section{Relating Expected Visiting Times and Quantitative Reachability}\label{sec:MC_Quantitative_Reachability}
We now relate \textit{expected visiting times} to \textit{quantitave reachability} for DTMCs. This has already been done in \cite[Lemma 3.5]{Baier_Relating_Reach_Prob} and \cite[Lemma 5.1]{Computing_EVTs_Stationary_Distr_in_MCs_Mertens}. Thus, we present their results in this section.

\begin{lemma}\label{lem:EVT_via_quant_reach}
    Given a DTMC $\MC$ and state $s\in S^\MC_{tr}$, the EVT of $s$ is given by
    \[ \Exp^\MC[vt_s] = \frac{Pr^{\MC}(\lozenge s)}{1-Pr^{\MC}_{s}(\cCircle\lozenge s)}\ .\]
\end{lemma}

In other words, we can calculate the EVT of a DTMC $\MC$ with only two reachability probabilities. For a proof of \Cref{lem:EVT_via_quant_reach}, see \cite[Lemma 3.5]{Baier_Relating_Reach_Prob} and \cite[Lemma 5.1]{Computing_EVTs_Stationary_Distr_in_MCs_Mertens}.
