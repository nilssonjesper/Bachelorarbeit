\chapter{\textit{Interval Markov Chains}}
\label{ch:Interval Markov Chains}

The focus of this thesis are Interval Markov Chains. In the following sections we will mainly discuss how the expected visiting times can be calculated and shortly examine stationary distributions of Interval Markov Chains.
 
We start by introducing concepts which we will use in the following sections.
\begin{definition}[Interval Markov Chain]\label{def:IMC}
    An interval discrete-time Markov chain (IDTMC) is a tuple
    $\IMC=(S,\PFlower,\PFupper,\Initlower,\Initupper)$, where
    \begin{enumerate}[label=(\roman*)]
        \item $S$ is a countable, nonempty set of states,
        \item $\PFlower: S \times S \rightarrow [0,1]$ is the transition probability function, where $\PFlower(s,s')$ gives the lower bound on the transition probability from state s to s',
        \item $\PFupper: S \times S \rightarrow [0,1]$ is the transition probability function, where $\PFupper(s,s')$ gives the upper bound on the transition probability from state s to s',
        \item $\Initlower: S \rightarrow [0,1]$ is the upper bound on the initial distribution, and
        \item $\Initupper: S \rightarrow [0,1]$ is the upper bound on the initial distribution.
    \end{enumerate}
\end{definition}

To resolve the uncertainty caused by the intervals, we need to define semantics to interpret the Interval Markov Chain. In other words we need to resolve an Interval Markov Chain to some set of Markov Chains that correspond to it. We say that all of these DTMCs $\MC_i$ satisfy the IDTMC $\IMC$ and denote it as $\MC_i \models \IMC$. We assume in this thesis that there exists at least one satisfying DTMC for every IDTMC.
\todo{gut so mit der assumption?}

In this paper, we will consider two popular semantics: the \textit{once-and-for-all} or \textit{Uncertain Markov Chain (UMC) semantic} and the \textit{IMDP semantic}.
We will first define the former, similar to \cite{Semantics_Quant-Analysis,Semantics_Model-Checking_omega-Regular,Semantics_LTL_Model_Checking}. 

\begin{definition}[Once-and-for-all/UMC Semantic]\label{def:once-and-for-all_semantic}
    An arbitrary DTMC $\MC$ satisfies an IDTMC $\IMC$ if and only if $\PFlower^{\IMC}(s,s')\leq\PF^{\MC}(s,s')\leq\PFupper^{\IMC}(s,s')$ and $\Initlower^{\IMC}(s)\leq\iota_{init}^{\MC}(s)\leq\Initupper^{\IMC}(s)$ for all $s,s'\in S^\IMC = S^\MC$. 
    
    We will denote this as $\MC\models_{\text{U}}\IMC$.
\end{definition}
In other words, any DTMC whose initial distribution and transition probabilities lie in the intervals defined by the IDTMC is satisfactory. Moreover, notice that the satisfaying DTMCs have the same state size (amount of states) as the IDTMC.

\end{example}

The second semantic which we will define, is the \textit{IMDP semantic}. There are two common definitions for this semantic. We will start by introducing the one that can be found in \cite{reachability_in_pIMCs_using_constraints} or \cite{Semantics_Quant-Analysis} and then continue with the other definition found in \cite{Model-Checking_presence_Uncertainties} or \cite{Semantics_Model-Checking_omega-Regular}.

\begin{definition}[IMDP semantic 1]\label{def:IMDP_semantic}
    An arbitrary DTMC $\MC=(T,\PF,\iota_{init})$ with $|T| \geq |S|$ (or $S \subseteq T$) satisfies an IDTMC $\IMC = (S,\PFlower,\PFupper,\Initlower,\Initupper)$ if and only if there exists a surjective mapping $\tau: T\rightarrow S$ such that
    \begin{enumerate}[label=(\roman*)]
        % \item $\tau(t) = s\in S \implies \Initlower(s) \leq \iota_{init}(t)\leq \Initupper(s)$
        \item for every $s\in S$ there exists exactly one $t\in T$ with $\tau(t) = s$ such that $\Initlower(s) \leq \iota_{init}(t)\leq \Initupper(s)$. Thus, for all other $\tau(t_i)=s$ and $t_i \neq t \implies \iota_{init}(t_i)=0\ .$
        \item $\PFlower(\tau(t),\tau(t')) \leq \PF(t,t')\leq \PFupper(\tau(t),\tau(t'))$ for all $t,t'\in T\ .$
    \end{enumerate}
    We will denote this as $\MC\models_{I}\IMC$.
\end{definition}

Intuitively, the IMDP semantic allows for a probability distribution to be chosen at every step in each state within the constraints/bounds set by the IDTMC. In contrast to the UMC semantic, where each state in the satisfying DTMCs have a corresponding state in the IDTMC and thus a fixed probability distribution, while the IMDP semantic allows for multiple states in the satisfying DTMCs with different fixed probability distributions to be mapped to the same corresponding state in the IDTMC. We can thus imagine an IDTMC under the IMDP semantic as a Markov Decision Process.

\begin{definition}[Markov Descision Process (MDP)]\label{def:MDP}\cite{Bibel}\todo{größtenteils übernommen}
    A \textit{Markov Decision Process} (MDP) is a tuple $D = (S,Act,A,\PF,\iota_{init})$, where
    \begin{enumerate}[label=(\roman*)]
        \item $S$ is a countable set of states
        \item Act is a set of actions
        \item $A(s)\subseteq Act$ denotes the applicable actions for all states $s\in S$ 
        \item $\PF: S\times Act\times S \rightarrow [0,1]$ is the transition probability function such that $\sum_{s'\in S}\PF(s,\alpha, s') = 1$ for all $s\in S$ and $\alpha\in A(s)$
        \item $\iota_{init}: S \rightarrow [0,1]$ is the initial distribution such that $\sum_{s\in S}\iota_{init}(s)=1$
    \end{enumerate}
\end{definition}

The most intuitive reduction from an IDTMC $\IMC$ under the IMDP semantic to a MDP $\MDP$ is to define $S^\MDP = S^\IMC$ and an uncoutable set $\cup_{s\in S} A(s) = Act$ of actions where each action $\alpha \in A(s)$ corresponds to a probability distribution \todo{that is admissable} $\PFlower^\IMC(s,s')\leq \PF^\MDP(s,\alpha,s')\leq \PFupper^\IMC(s,s')$ (for $s'\in N(s)$). In other words, the actions $\alpha\in A(s)$ in a given state $s\in S$ correspond to the probability distributions that can be chosen in $s$ in any given step. However, as even the subsets $A(s)$ can be uncoutable, this reduction is trivially not "usable", as no algorithm, such as value or policy iteration, would terminate.

When defining EVTs for IDTMCs it is thus useful to define them as bounds for the EVTs of the satisfying DTMCs.
\begin{definition}[EVTs of IDTMCs]
    For a IDTMC $\IMC$, we define the \textit{upper expected visiting time} (uEVT) $\ExpUpper^\IMC[vt_s]$ and \textit{lower expected visiting time} (lEVT) $\ExpLower^\IMC[vt_s]$ for all states $s\in S^\IMC$, as follows
    \begin{enumerate}[label=(\roman*)]
        \item $\ExpUpper^\IMC[vt_s] = \Exp^\MC[vt_s]$, where $\MC \models \IMC$ and $\Exp^\MC[vt_s] \geq \Exp^{\MC'}[vt_s]$ for all $\MC'\models \IMC$.
        \item $\ExpLower^\IMC[vt_s] = \Exp^\MC[vt_s]$, where $\MC \models \IMC$ and $\Exp^\MC[vt_s] \leq \Exp^{\MC'}[vt_s]$ for all $\MC'\models \IMC$.
    \end{enumerate}
\end{definition}

\subsection{Relation between the semantics}\label{sec:relation_between_the_semantics}
Clearly, the IMDP semantic is more expressive than the UMC semantic \cite{Semantics_Quant-Analysis}. More specifically for any given IDTMC $\IMC$, a DTMC $\MC$ that satisfies $\IMC$ according to the UMC semantic, i.e. $\MC \models_U \IMC$, does also satisfy $\IMC$ according to the IMDP semantic, i.e. $\MC \models_I \IMC$ \cite{Semantics_Quant-Analysis}.
\begin{theorem}
    For any IDTMC $\IMC$, if $\MC \models_U \IMC$, then $\MC \models_I \IMC$
\end{theorem}
For this, we provide a slightly more detailed proof of \cite{Semantics_Quant-Analysis} (Remark 1).

\begin{proof}
    If $\MC \models_U \IMC$, then we define $T = S$ and $\tau(s) = s$. Then (i) of \cref{def:IMDP_semantic} is fulfilled as $\tau$ is bijective and $\iota_{init}(s) \in [\Initlower(s),\Initupper(s)]$ for all $s\in S$, as $\MC \models_U \IMC$. Moreover, (ii) is fulfilled as $\PF(s,t)\in[\PFlower(s,t),\PFupper(s,t)]$ for all $s,t\in S$, as $\MC \models_U \IMC$. Thus, we can conclude that $\MC \models_I \IMC$.
\end{proof}

Importantly, the two semantics have the same maximum and minimum reachability probability for any given (initial) state, according to \cite{reachability_in_pIMCs_using_constraints} and \cite{complexity_model_checking_interval-valued_DTMCs}. Moreover, computing the maximum or minimum reachability probability is shown to be P-complete for the IMDP semantic, and thus also for the UMC semantic, in \cite{complexity_model_checking_interval-valued_DTMCs}.

\section{Calculating Expected Visiting Times of IDTMCs}
We will now have a look at how the \textit{expected visiting times} for IDTMCs can be calculated

The most intuitive upper and lower bounds for the uEVTs and lEVTs of IDTMCs can be derived by using \cref{eq:EVT_DTMC_iterative_characterization} and the upper and lower transition probability functions and initial distributions defined in \cref{def:IMC}.

\begin{theorem}[Upper and Lower Bounds for uEVTs and lEVTs]\label{th:loose_bounds_for_evts}
    For any IDTMC $\IMC$, the uEVT $\ExpUpper[vt_s]$ is bounded from above by $\Exp_{upp}[vt_s] = \Initupper(s)+\sum_{t\in S_{tr}}\PFupper(t,s)^\T\cdot \Exp_{upp}[vt_t]$ and the lEVT $\ExpLower[vt_s]$ is bounded from below by $\Exp_{low}[vt_s] = \Initlower(s)+\sum_{t\in S_{tr}}\PFlower(t,s)^\T\cdot \Exp_{low}[vt_t]$
\end{theorem}
\begin{proof}
    For any IDTMC $\IMC$ there exists a DTMC $\MC$ that satisfies $\IMC$, i.e., $\MC \models \IMC$, and $\Exp^\MC[vt_s] = \ExpUpper^\IMC[vt_s]$. As $\MC \models \IMC$, it follows that $\PF(s,s')\leq \PFupper(s,s')$ for all $s,s'\in S$.

    Thus, $\Exp^\MC[vt_s] = \iota_{init}(s)+\sum_{t\in S_{tr}}\PF(t,s)^\T\cdot \Exp[vt_t] \leq \Initupper(s)+\sum_{t\in S_{tr}}\PFupper(t,s)^\T\cdot \Exp_{upp}[vt_t] = \Exp_{upp}^\IMC[vt_s]$.
    
    The identical argument can be made to prove the lower bound for the lEVT.
\end{proof}

\emph{\textbf{Remark.} Existence of DTMC with optimal reachability.}\label{rem:existence}
For every transient state $t\in S_{tr}$ there exists a DTMC
$\MC\models_U\IMC$ with $Pr_t^\MC(\Diamond s) = \operatorname{sup}_{\MC_i\models_U \IMC}Pr_{t}^{\MC_i}(\Diamond s)$. This follows directly from the compactness and continuity of the polytope of DTMCs satisfying $\IMC$; it is not reproved here, only reused. To shorten the notation we will denote $\dot{Pr^\MC_t}(\Diamond s) = \operatorname{sup}_{\MC_i\models_U \IMC}Pr_{t}^{\MC_i}(\Diamond s)$

\begin{theorem}\label{th:max_reach_prob_for_intermediate_states}
    Given an IDTMC $\IMC$, a transient state $t\in S^\IMC$, a (goal) state $s\in S^\IMC$, and a DTMCs $\MC$ with $\MC\models \IMC$. (Positive transition/reachability probability from t to s, i.e. there needs to exist a path fragment from t to s)

    $\MC$ has the maximum reachability probability from $t$ to $s$, i.e., $Pr^{\MC}_{t}(\Diamond s) = \operatorname{sup}_{\MC_i \models \IMC}Pr^{\MC_i}_{t}(\Diamond s)$, if and only for all $u\in I^\MC_{ts}$:
    \[Pr^{\MC}_{u}(\Diamond s) = \operatorname{sup}_{\MC_i \models \IMC}Pr^{\MC_i}_{u}(\Diamond s)\]
\end{theorem}

\begin{corollary}\label{th:two_DTMCs_compatible_for_max_reach}
    Given an IDTMC $\IMC$, two transient state $t_1, t_2\in S^\IMC$, a (goal) state $s\in S^\IMC$, and two DTMCs $\MC_1,\MC_2$ with $\MC_1,\MC_2\models_U \IMC$ and $Pr^{\MC_1}_{t_1}(\Diamond s) = \operatorname{sup}_{\MC \models_U \IMC}Pr^{\MC}_{t_1}(\Diamond s)$ and $Pr^{\MC_2}_{t_2}(\Diamond s) = \operatorname{sup}_{\MC \models_U \IMC}Pr^{\MC}_{t_2}(\Diamond s)$. In other words the DTMCs have a maximum reachability probability for $t_1$ and $t_2$, respectively.

    For all $u\in I^{\MC_1}_{t_1s} \cap I^{\MC_2}_{t_2s}$, the reachability probabilities $Pr^{\MC_1}_u(\Diamond s) = Pr^{\MC_2}_u(\Diamond s)$ are identical.
\end{corollary}

Thus, $Pr^{\MC_1}_u(\Diamond s) = Pr^{\MC_2}_u(\Diamond s)$ for all $u\in I^{\MC_1}_{t_1s} \cap I^{\MC_2}_{t_2s}$.
\end{proof}

Recall, that we concluded in \cref{sec:IMC_Quantitative_Reachability} that the uEVT and lEVT of a given IDTMC $\IMC$ can be calculated by maximizing or minimizing the term $\sum_{t\in \Strin} \frac{Pr_t(\Diamond s)}{1-Pr_s(\cCircle\Diamond s)} \cdot \iota_{init}(t)$ for all DTMCs $\MC \models \IMC$. Intuitively, we can thus find the lEVTs and uEVTs by maximizing or minimizing the reachability probability from the initial state $t$ to the given state $s$ ($Pr_t(\Diamond s)$) and from $s$ back to itself ($Pr_s(\cCircle\Diamond s)$). As shown in \cite{complexity_model_checking_interval-valued_DTMCs} the problem of finding this supremum or infimum for a given IDTMC is P-complete. \begin{definition}[Intermediate sets are closed under composition]\label{obs:closure}
For any DTMC $\MC$ and states $t,s,u,w\in S^\MC$: if $u\in I^\MC_{ts}$ and $w\in I^\MC_{us}$,
then $w\in I^\MC_{ts}\cup\{t\}$.
\end{definition}
\begin{proof}
Let $\rho$ witness $u\in I^\MC_{ts}$, i.e.\ a path fragment $t\to\cdots\to u\to\cdots\to s$
passing through $u$ at some index $k$, and let $\sigma$ witness $w\in I^\MC_{us}$, i.e.\ a path
fragment $u\to\cdots\to w\to\cdots\to s$. Truncating $\rho$ at its first visit to $u$ and
appending $\sigma$ yields a valid path fragment from $t$ to $s$ (transitions still respect
$\PF^\MC$) that passes through $w$. Hence $w$ is intermediate for $(t,s)$, unless $w=t$.
\end{proof}

\begin{corollary}\label{cor:closure}
If $R\subseteq S^\MC$ contains $t$ and $I^\MC_{ts}$, then $I^\MC_{us}\subseteq R\cup\{s\}$ for
every $u\in R$. We call such an $R$ \emph{closed (w.r.t.\ $\MC$ and $s$)}.
\end{corollary}

\begin{lemma}[Persistence on a closed region]\label{lem:persistence}
Let $\MC\models_U\IMC$ and let $R\subseteq S$ be closed w.r.t.\ $\MC$ and $s$ (\cref{cor:closure})
with $Pr_u^\MC(\Diamond s) = M(u)$ for every $u\in R$. If $\MC'\models_U\IMC$ satisfies
$\PF^{\MC'}(u,\cdot) = \PF^\MC(u,\cdot)$ for every $u\in R$, then
$Pr_u^{\MC'}(\Diamond s) = M(u)$ for every $u\in R$ as well.
\end{lemma}
\begin{proof}
Fix $u\in R$. Every path fragment $\pi\in\Diamond_u s$ (w.r.t.\ $\MC$) has all its intermediate
states in $I^\MC_{us}\subseteq R\cup\{s\}$ (\cref{cor:closure}), so every transition of $\pi$
leaves from a state in $R$; since $\PF^{\MC'}=\PF^\MC$ on $R$, $\pi$ has the identical
probability under $\MC'$, and is a valid (positive-probability) path fragment of $\MC'$ too.
Summing over these paths, $Pr_u^\MC(\Diamond s) \le Pr_u^{\MC'}(\Diamond s)$. Since
$\MC'\models_U\IMC$, also $Pr_u^{\MC'}(\Diamond s) \le M(u) = Pr_u^\MC(\Diamond s)$. Hence equality.
\end{proof}

\begin{lemma}[One-state extension]\label{lem:extension}
Let $R\subseteq S$, $\MC\models_U\IMC$ be closed and optimal on $R$ as in
\cref{lem:persistence}, and let $t^*\in S_{tr}\setminus R$. Let $\MC_{t^*}\models_U\IMC$ satisfy
$Pr_{t^*}^{\MC_{t^*}}(\Diamond s) = M(t^*)$ (\cref{rem:existence}), and set
$D := I^{\MC_{t^*}}_{t^*s}\cup\{t^*\}$. Define $\MC'$ by
\[
  \PF^{\MC'}(u,\cdot) \;:=\;
  \begin{cases}
    \PF^{\MC_{t^*}}(u,\cdot) & u \in D\setminus R \\
    \PF^{\MC}(u,\cdot)       & \text{otherwise.}
  \end{cases}
\]
(I.e.\ $\MC'$ equals $\MC$ except that rows of states in $D\setminus R$ are overwritten by
$\MC_{t^*}$'s rows.) Then $\MC'\models_U\IMC$, and $Pr_u^{\MC'}(\Diamond s) = M(u)$ for every
$u \in R\cup\{t^*\}$.
\end{lemma}
\begin{proof}
$\MC' \models_U \IMC$ is immediate, since every row of $\MC'$ is copied verbatim from a DTMC
already satisfying $\IMC$. Optimality on $R$ follows directly from \cref{lem:persistence},
since $\PF^{\MC'} = \PF^{\MC}$ on $R$.

It remains to show $Pr_{t^*}^{\MC'}(\Diamond s) = M(t^*)$. Write $B := D\setminus R$ (so
$t^*\in B$) and $A := D\cap R$. By construction, $\PF^{\MC'} = \PF^{\MC_{t^*}}$ on all of $B$.
Consider the DTMC $X$ obtained by running $\MC'$ started at $t^*$, and $Y$ obtained by running
$\MC_{t^*}$ started at $t^*$. Because their transition laws agree on $B$, we may couple $X$ and
$Y$ on the same probability space so that $X_k = Y_k$ for all $k \le \tau$, where
$\tau := \min\{k \ge 1 : X_k \notin B\}$ is the first exit time from $B$ (a stopping time for
both processes, by the coupling).

At time $\tau$, $X_\tau = Y_\tau$ lands in exactly one of three disjoint sets:
\begin{itemize}
  \item $\{s\}$;
  \item $A = D\cap R \subseteq R$ (more generally, landing anywhere in $R$ is possible — this
        can only happen via a transition out of $B \subseteq D$ under $\PF^{\MC_{t^*}}$, so in
        particular $A\subseteq R$ covers this; we simply write $u\in R$ for the landing state);
  \item some $d \notin R\cup\{s\}$; since $\tau$ exits $B=D\setminus R$ and $d\notin R$, also
        $d\notin D$ (as $D = A \cup B$), i.e.\ $d\notin I^{\MC_{t^*}}_{t^*s}\cup\{t^*,s\}$, so
        by definition $Pr_d^{\MC_{t^*}}(\Diamond s) = 0$.
\end{itemize}
By the strong Markov property applied to $Y$ under $\MC_{t^*}$ at the stopping time $\tau$
(standard first-step analysis for DTMCs, cf.\ the argument underlying
\cref{th:max_reach_prob_for_intermediate_states}):
\begin{equation}\tag{$\ast$}
  M(t^*) = Pr_{t^*}^{\MC_{t^*}}(\Diamond s)
  = P(Y_\tau = s)\cdot 1
  + \sum_{u\in R} P(Y_\tau = u)\cdot Pr_u^{\MC_{t^*}}(\Diamond s)
  + \underbrace{\sum_{d\notin R\cup\{s\}} P(Y_\tau=d)\cdot 0}_{=0}.
\end{equation}
Applying the same decomposition to $X$ under $\MC'$:
\[
  Pr_{t^*}^{\MC'}(\Diamond s)
  = P(X_\tau=s)\cdot 1 \;+\; \sum_{u\in R} P(X_\tau=u)\cdot Pr_u^{\MC'}(\Diamond s)
  \;+\; \sum_{d\notin R\cup\{s\}} P(X_\tau=d)\cdot Pr_d^{\MC'}(\Diamond s).
\]
By the coupling, $P(X_\tau=\cdot) = P(Y_\tau=\cdot)$. By \cref{lem:persistence},
$Pr_u^{\MC'}(\Diamond s) = M(u) = Pr_u^{\MC_{t^*}}(\Diamond s)$ for every $u\in R$ (the last
equality since $\MC_{t^*}$ is optimal on all of $I^{\MC_{t^*}}_{t^*s}\supseteq A$ by
\cref{th:max_reach_prob_for_intermediate_states}, and both sides equal $M(u)$). The last sum is
$\ge 0$. Hence, comparing with $(\ast)$,
\[
  Pr_{t^*}^{\MC'}(\Diamond s) \;\ge\; P(Y_\tau=s) + \sum_{u\in R}P(Y_\tau=u)\,M(u) + 0 \;=\; M(t^*).
\]
On the other hand $Pr_{t^*}^{\MC'}(\Diamond s) \le M(t^*)$ trivially, since $\MC'\models_U\IMC$
and $M(t^*)$ is the supremum over all such DTMCs. Hence $Pr_{t^*}^{\MC'}(\Diamond s) = M(t^*)$.
\end{proof}

\begin{theorem}
Given an IDTMC $\IMC$ and a (goal) state $s\in S$ there exists a DTMC $\MC \models_U \IMC$ such
that $Pr_t^\MC(\Diamond s) = \operatorname{sup}_{\MC_i \models_U \IMC} Pr_t^{\MC_i}(\Diamond s)$
for all transient states $t\in S_{tr}$.
\end{theorem}
\begin{proof}
Since $S$ is countable (\cref{def:IMC}(i)), so is $S_{tr}$; let $t_1,t_2,t_3,\dots$ enumerate it
(if $S_{tr}$ is finite the construction below simply terminates after $|S_{tr}|$ steps and no
limit is needed).

\emph{Construction.} Let $\MC^{(1)}\models_U\IMC$ satisfy $Pr_{t_1}^{\MC^{(1)}}(\Diamond s) =
M(t_1)$ (\cref{rem:existence}) and set $R_1 := I^{\MC^{(1)}}_{t_1 s}\cup\{t_1,s\}$; by
\cref{th:max_reach_prob_for_intermediate_states}, every $u\in R_1$ satisfies
$Pr_u^{\MC^{(1)}}(\Diamond s) = M(u)$, and $R_1$ is closed by \cref{cor:closure}.

Inductively, given $\MC^{(n)}\models_U\IMC$ and $R_n\ni s$, closed and optimal
(i.e.\ $Pr_u^{\MC^{(n)}}(\Diamond s)=M(u)$ for all $u\in R_n$): if $t_{n+1}\in R_n$, set
$\MC^{(n+1)}:=\MC^{(n)}$, $R_{n+1}:=R_n$. Otherwise apply \cref{lem:extension} with
$R=R_n,\ \MC=\MC^{(n)},\ t^*=t_{n+1}$ to obtain $\MC^{(n+1)}\models_U\IMC$ optimal on
$R_n\cup\{t_{n+1}\}$; set $R_{n+1} := R_n \cup I^{\MC^{(n+1)}}_{t_{n+1}s}\cup\{t_{n+1}\}$. By
\cref{th:max_reach_prob_for_intermediate_states} applied to $\MC^{(n+1)}$ (now known optimal at
$t_{n+1}$), every $u\in I^{\MC^{(n+1)}}_{t_{n+1}s}$ is optimal in $\MC^{(n+1)}$ too, so $R_{n+1}$
is fully optimal; $R_{n+1}$ is closed by applying \cref{cor:closure} to each generator
$t_1,\dots,t_{n+1}$ in turn.

Crucially, by construction (either branch), $\PF^{\MC^{(n+1)}}(u,\cdot) = \PF^{\MC^{(n)}}(u,\cdot)$
for every $u\in R_n$ — rows are only ever overwritten on $D\setminus R_n$, disjoint from $R_n$.
Since $R_n\subseteq R_{n+1}$ for all $n$, this "freezing" persists: for all $m\ge n$,
$\PF^{\MC^{(m)}}(u,\cdot) = \PF^{\MC^{(n)}}(u,\cdot)$ for every $u \in R_n$.

\emph{Passing to the limit.} For a state $u\in S$, let $m(u) := \min\{n : u\in R_n\}$ if it
exists. By the freezing property, $\PF^{\MC^{(n)}}(u,\cdot)$ is constant in $n$ for
$n\ge m(u)$; if $u$ never enters any $R_n$ its row is likewise never touched past
$\MC^{(1)}$. Either way $\lim_{n\to\infty}\PF^{\MC^{(n)}}(u,\cdot)$ exists for every $u$; define
$\MC^{(\infty)}$ by these limiting rows. Since each row is copied from some
$\MC^{(n)}\models_U\IMC$, we get $\MC^{(\infty)}\models_U\IMC$.

For each $i$, rows agree between $\MC^{(\infty)}$ and $\MC^{(i)}$ on all of $R_i$ (both equal
the frozen value from step $i$ onward), $R_i$ is closed and optimal for $\MC^{(i)}$, and
$t_i\in R_i$. By \cref{lem:persistence} (with $\MC=\MC^{(i)}$, $\MC'=\MC^{(\infty)}$, $R=R_i$),
\[
  Pr_{t_i}^{\MC^{(\infty)}}(\Diamond s) = M(t_i).
\]
As $t_1,t_2,\dots$ enumerate all of $S_{tr}$, $\MC^{(\infty)}$ simultaneously attains
$Pr_t^{\MC^{(\infty)}}(\Diamond s) = \sup_{\MC_i\models_U\IMC} Pr_t^{\MC_i}(\Diamond s)$ for every
transient state $t\in S_{tr}$.
\end{proof}
