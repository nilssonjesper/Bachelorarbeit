\chapter{\textit{EVTs in IDTMCs}}
\label{ch:EVTs_in_IDTMCs}

We continue in this chapter by defining \textit{expected visiting times} (EVTs) for IDTMCs. As we discussed in the previous section, IDTMCs can be seen as a set of DTMCs that satisfy the IDTMC according to the given semantic. These different DTMCs can have varying EVTs for a given state $s$ in the IDTMC, thus we are interested in the upper and lower bound for the EVTs of $s$, i.e., in the largest and smallest EVT of $s$ among the satisfying DTMCs. To this end, we fix an IDTMC $\IMC = (S^\IMC,\PFlower,\PFupper,\Initlower,\Initupper)$, a DTMC $\MC = (S^\MC,\PF,\iota_{init})$, a nature $\eta:Paths_{fin}^\IMC\rightarrow Steps^\IMC$, and stationary nature $\eta_{st}:S\IMC\rightarrow Steps^\IMC$ for the rest of this chapter.

\begin{definition}[EVTs of IDTMCs]\label{def:EVTs_of_IDTMCs}
    For a IDTMC $\IMC$, we define the \textit{upper expected visiting time} (uEVT) $\ExpUpper^\IMC[vt_s]$ and \textit{lower expected visiting time} ($\ell$EVT) $\ExpLower^\IMC[vt_s]$ for all states $s\in S^\IMC$, as follows for the UMC semantic
    \begin{enumerate}[label=(\roman*)]
        \item $\ExpLower^\IMC[vt_s] = \inf_{\MC\models_U\IMC} \Exp^\MC[vt_s]$
        \item $\ExpUpper^\IMC[vt_s] = \sup_{\MC\models_U\IMC} \Exp^\MC[vt_s]$
    \end{enumerate}
    and the IMDP semantic
    \begin{enumerate}[label=(\roman*)]
        \item $\ExpLower^\IMC[vt_s]
        = \inf_{\MC \models_I \IMC} \Exp^\MC[vt_T]$
        \item $\ExpUpper^\IMC[vt_s]
        = \sup_{\MC \models_I \IMC} \Exp^\MC[vt_T]\ ,$
    \end{enumerate}
    where $T = \tau^{-1}(s)$.
\end{definition}

\section{Calculating Expected Visiting Times of IDTMCs}\label{sec:calculating_expected_visiting_times_of_IDTMCs}
In this section, we define loose bound for the $\ell$EVTs and uEVTs and provide precise characterizations for specific $\ell$EVTs and uEVTs under the UMC semantic.

We start by defining the loose bounds. Notice, that the most intuitive upper and lower bounds for the uEVTs and $\ell$EVTs of IDTMCs under the UMC semantic can be derived by using \Cref{eq:EVT_DTMC_iterative_characterization} and the upper and lower transition probability functions, as well as the initial distributions defined in \Cref{def:IMC}.

\begin{theorem}[Upper and Lower Bounds for uEVTs and lEVTs]\label{th:loose_bounds_for_evts}
    For a given IDTMC $\IMC$ and state $s\in S^\IMC$, the uEVT of $s$ is bounded from above by 
    \[\ExpUpper[vt_s] \leq \Exp_{upp}[vt_s] \coloneq \Initupper(s)+\sum_{t\in S}\PFupper(t,s)\cdot \Exp_{upp}[vt_t]\]
    and the $\ell$EVT of $s$ is bounded from below by 
    \[\ExpLower[vt_s] \geq \Exp_{low}[vt_s] = \Initlower(s)+\sum_{t\in S}\PFlower(t,s)\cdot \Exp_{low}[vt_t]\]
    for all $s\in S^\IMC$.
\end{theorem}

\emph{\textbf{Intermediate States.}} Using the notion of finite paths, we introduce \textit{intermediate states}.

\begin{definition}[Intermediate States]\label{def:intermediate_state}
    Given a DTMC $\MC$, a set of states $T\subseteq S$, and a state $s \in S$, then $u\in S$ is \textit{intermediate} if and only if there exists path $\pi \in Paths^\MC_{fin}$, such  that $\pi[0]\in T$, $last(\pi) = s$, and $\pi[k] = u$ for some $k\in \underline{|\pi|}$. 
\end{definition}
In other words, there exists a finite path from some $t\in T$ to $s$ in $\MC$ that visits $u$.
We denote the set of these intermediate states as $I^\MC_{T,s}$ for a set of states $T\in S$ and state $s\in S$ in $\MC$. Moreover, if $T$ is a singleton set, i.e., $T =\{t\}$, then we simply denote the set of intermediate states as $I^\MC_{t,s}$.

\begin{theorem}\label{th:max_reach_prob_for_intermediate_states}
    Given an IDTMC $\IMC$, states $t,s\in S^\IMC$, and a DTMC $\MC$ with $\MC\models_U \IMC$.

    If $\MC$ has the maximum reachability probability from $t$ to $s$, i.e., $Pr^{\MC}_{t}(\lozenge s) = \Prupper^{\IMC}_{t}(\lozenge s)$, then for all $u\in I^\MC_{t,s}$:
    \[Pr^{\MC}_{u}(\lozenge s) = \Prupper^{\IMC}_{u}(\lozenge s)\]

    Conversely, if $\MC$ has the minimum reachability probability from $t$ to $s$, i.e., $Pr^{\MC}_{t}(\lozenge s) = \Prlower^{\IMC}_{t}(\lozenge s)$, then for all $u\in I^\MC_{t,s}$:
    \[Pr^{\MC}_{u}(\lozenge s) = \Prlower^{\IMC}_{u}(\lozenge s)\]
\end{theorem}

In other words, if the reachability probability, under the UMC semantic, from $t$ to $s$ is optimal, then the reachability probability of all intermediate states is optimal as well.

\subsection{UMC semantic}\label{sec:UMC_semantic}
In this section we examine how the precise values of the uEVTs and lEVTs can be calculated for IDTMCs under the UMC semantic.

As defined, there can be multiple DTMCs $\MC$ that satisfy an IDTMC $\IMC$ with differing transition probability functions $\PF^{\MC}$ and initial distributions $\iota_{init}^{\MC}$. To determine the uEVT and $\ell$EVT for a given state $s\in S^\IMC$, we thus have to find the satisfying DTMCs that maximize and minimze \Cref{eq:EVT_DTMC_iterative_characterization}, respectively.
In other words, we need to solve the equations
\[\Exp[vt_s] = \operatorname{opt}_{\MC\models\IMC} \left(\iota_{init}(s) + \sum_{t\in S_{tr}}\PF^\MC(t,s)\cdot\Exp[vt_t]\right), \qquad \operatorname{opt}\in\{\min,\max\}. \]

% As we concluded, the $\ell$EVT and uEVT of a given state $s$ in an IDTMC, can be calculated by computing the reachability probabilities $\Prupper^\IMC(\lozenge s)$ and $\Prupper^\IMC(\cCircle \lozenge s)$ or $\Prlower^\IMC(\lozenge s)$ and $\Prlower^\IMC(\cCircle \lozenge s)$. 
In \cite{complexity_model_checking_interval-valued_DTMCs}, the authors construct the following LP (which we have rewritten slightly) to compute any maximum or minimum reachability, respectively, for a set of nodes $T\subseteq S$, using the fixed-initial-state-definition:

\[
   \begin{aligned}
        \operatorname{opt} \quad & \sum_{s_i\in S\backslash T}Pr^\MC_{s_i}(\lozenge T) & &\\
        \text{s.t.} \quad & Pr^\MC_{s_i}(\lozenge T) \sim \sum_{s_j\in S\backslash T} \PF^\MC({s_i},s_j)Pr^\MC_{s_j}(\lozenge T) + \sum_{s_j\in T}\PF^\MC(s_i,s_j) & \forall s_i \in S\backslash T, \qquad & (1)\\
        & \PF^\MC(s_i) \in Steps^\IMC(s_i) & \forall s_i\notin T, \qquad & (2)\\
        & Pr^\MC_{s_i}(\lozenge T) = 1 & \forall s_i \in T, \qquad & (3)\\
        % & \sum_{s_j\in N(s)} \PF(s_i,s_j) = 1 && \forall s_i\in S_{tr} & (3)\\
        % & \PFlower^\IMC(s_i,s_j) \leq \PF(s_i,s_j) \leq \PFupper^\IMC(s_i,s_j) && \forall s_i,s_j\in S_{tr}^\IMC & (4)\\
    \end{aligned}
\]
where $(\operatorname{opt},\sim) \in \{(\max,\leq),(\min,\geq)\}$.

Notice, that $Steps^\IMC(s_i)$ can be infinte for a given $s_i \in S^\IMC$. However, as described in \cite{complexity_model_checking_interval-valued_DTMCs} and \cite{Model-Checking_presence_Uncertainties}, $Steps\IMC(s_i)$ can be restricted by introducing the notion of \textit{basic feasible solutions}. Using this notion, we can obtain an upper bound on the size of $Steps^\IMC(s_i)$ in terms of the number of states $|S^\IMC|$. Specifically, 
\[|Steps^\IMC(s_i)| = \mathcal{O}(|S^\IMC|2^{|S^\IMC|-1})\ ,\]
see \cite[Lemma 6]{Model-Checking_presence_Uncertainties} which implies that the LP has an exponential number of constraints.

Recall, that under the UMC semantic, the $\ell$EVT and uEVT of $s$ can be expressed as a rationaly function of the reachability probabilities $\Prupper^\IMC(\lozenge s)$ and $\Prupper^\IMC(\cCircle \lozenge s)$, or $\Prlower^\IMC(\lozenge s)$ and $\Prlower^\IMC(\cCircle \lozenge s)$, respectively, see \Cref{th:u/lEVTs_via_reach_and_semantics_coincide}. In this subsection we will look at how uEVTs and lEVTs can be calculated for the IMDP semantic.

By showing this approach both the relation between the reachability probabilities and expected visiting times, as well as the differences between the UMC and IMDP semantic become more apparent. Similar to IDTMC, so-called Bounded-Parameter Markov Decision Processes (BMDPs) were introduced to capture potential imprecision of MDPs. We define these BMDPs based on \cite{Givan_Bounded_Parameter_MDP_discounted,Tewari_Bounded_Parameter_MDP}.

\begin{definition}[Bounded-Parameter Markov Decision Processes]
    A \textit{Bounded-Paramter Markov Decision Process} (BMDP) is a tuple $\BMDP = (S^\BMDP,Act^\BMDP,\PFlower^\BMDP,\PFupper^\BMDP,s_0^\BMDP,\rewLower^\BMDP,\rewUpper^\BMDP)$, where
    \begin{enumerate}[label=(\roman*)]
        \item $S^\BMDP$ is a countable set of states,
        \item $Act^\BMDP$ is a set of actions,
        \item $\PFlower^\BMDP: S^\BMDP \times Act^\BMDP \times S^\BMDP \rightarrow [0,1]$ is the lower bound on the transition probability function,
        \item $\PFupper^\BMDP: S^\BMDP \times Act^\BMDP \times S^\BMDP \rightarrow [0,1]$ is the upper bound on the transition probability function,
        \item $s_0^\BMDP$ is the fixed initial state,
        \item $\rewLower^\BMDP: S^\BMDP \rightarrow\RR$ is the lower bound on the reward function,
        \item $\rewUpper^\BMDP: S^\BMDP \rightarrow\RR$ is the upper bound on the reward function,
    \end{enumerate}
    such that $\PFlower^\BMDP(s_i,\alpha,s_j) \leq \PFupper^\BMDP(s_i,\alpha,s_j)$ for all $s_i,s_j\in S^\BMDP$, $\alpha \in Act^\BMDP$ and $\rewLower^\BMDP(s) \leq \rewUpper^\BMDP(s)$ for all $s\in S^\BMDP$.
\end{definition}
Whenever the MDP $\BMDP$ is evident from the context, we will omit the superscript $\BMDP$.

For the rest of this section, we fix a BMDP $\BMDP = (S^\BMDP,Act^\BMDP,\PFlower^\BMDP,\PFupper^\BMDP,s_0^\BMDP,\rewLower^\BMDP,\rewUpper^\BMDP)$ and an MDP $\MDP = (S^\MDP,Act^\MDP,\PF^\MDP,s_0^\MDP,rew^\MDP)$.
Similarly to IDTMCs, a BMDP $\BMDP$ defines a set of satisfying MDPs $\MDP$. An MDP $\MDP$ satisfies $\BMDP$ if and only if 
\begin{itemize}
    \item $S^\MDP = S^\BMDP$,
    \item $Act^\MDP = Act^\BMDP$,
    \item $\PF^\MDP(s_i,\alpha,s_j) \in [\PFlower^\BMDP(s_i,\alpha,s_j),\PFupper^\BMDP(s_i,\alpha,s_j)]$ for all $s_i,s_j\in S^\MDP$, $\alpha\in Act^\MDP$, and
    \item $rew^\MDP(s) \in [\rewLower^\BMDP(s),\rewUpper^\BMDP(s)]$ for all $s\in S^\MDP$.
\end{itemize}
Notice, that this is simply the UMC semantic for BMDPs, see \Cref{def:once-and-for-all_semantic}. We denote that an MDP $\MDP$ satisfies a BMDP $\BMDP$ as $\MDP \models \BMDP$.

We now define an IDTMC $\IMC = (S^\IMC,\PFlower^\IMC,\PFupper^\IMC,s_0)$ under the fixed-initial-state definition. From this IDTMC $\IMC$, given a state $s\in S^\IMC$, we continue by constructing the following BMDP $\BMDP_s$.

\emph{\textbf{Construction.}} We define $\BMDP_s = (S^\IMC,Act^{\BMDP_s},\PFlower^{\BMDP_s},\PFupper^{\BMDP_s},s_0^\IMC,\rewLower^{\BMDP_s},\rewUpper^{\BMDP_s})$ with $Act^{\BMDP_s} = \{\alpha\}$,
\[\PFlower^{\BMDP_s}(s_i,\alpha,s_j) = \PFlower^\IMC(s_i,s_j) \qquad \text{, and} \qquad \PFupper^{\BMDP_s}(s_i,\alpha,s_j) = \PFupper^\IMC(s_i,s_j)\]
for all $s_i,s_j \in S^\IMC$.
Furthermore,
\[
\rewLower^{\BMDP_s}(s_i)
=
\rewUpper^{\BMDP_s}(s_i)
=
\begin{cases}
    1, & \text{if } s_i = s,\\
    0, & \text{otherwise,}
\end{cases}
\]
for all $s_i \in S^\IMC$

\begin{lemma}[Correspondence between satisfying DTMCs and MDPs]\label{lem:correspondance-between-satisfying-dtmcs-and-mdps}
\label{lem:DTMC_MDP_correspondence}
Let $\IMC = (S^\IMC,\PFlower^\IMC,\PFupper^\IMC,s_0)$ be an IDTMC under the fixed-initial-state definition, $s\in S^\IMC$, and let $\BMDP_s$ be the BMDP constructed above. Then, for every DTMC $\MC$, $\MC\models_U\IMC$ if and only if there exists an MDP $\MDP$ such that $\MDP\models\BMDP_s$ and the probability measures induced by $\MC$ and $\MDP$ correspond under the identification of their paths.
\end{lemma}

We provide a proof for this lemma.
\begin{proof}
First, let $\MC=(S^\MC,\PF^\MC,s_0^\MC)$ be a DTMC such that $\MC\models_U\IMC$. We construct an MDP $\MDP=(S^\MDP,Act^\MDP,\PF^\MDP,s_0^\MDP,rew^\MDP)$ by defining $S^\MDP=S^\IMC$, $Act^\MDP=\{\alpha\}$, $\PF^\MDP(s_i,\alpha,s_j)=\PF^\MC(s_i,s_j)$ for all $s_i,s_j\in S^\IMC$, and $s_0^\MDP=s_0^\MC$. Furthermore, let 
\[rew^\MDP(s)= \begin{cases}
    1, & \text{if } s_i = s, \\
    0, & \text{otherwise,}
\end{cases}\]
for $s\in S^\IMC$.

Since $\MC\models_U\IMC$, we have $\PFlower^\IMC(s_i,s_j)\leq\PF^\MC(s_i,s_j)\leq\PFupper^\IMC(s_i,s_j)$ for all $s_i,s_j\in S^\IMC$. By the construction of $\BMDP_s$, this implies
\[
\PFlower^{\BMDP_s}(s_i,\alpha,s_j)\leq\PF^\MDP(s_i,\alpha,s_j)\leq\PFupper^{\BMDP_s}(s_i,\alpha,s_j).
\]
Moreover, $\rewLower^{\BMDP_s}(s_i)=rew^\MDP(s_i)=\rewUpper^{\BMDP_s}(s_i)=1$ for $s_i = s$ and $0$ in all other cases. Thus, $\MDP\models\BMDP_s$.

Conversely, let $\MDP=(S^\MDP,Act^\MDP,\PF^\MDP,s_0^\MDP,rew^\MDP)$ be an MDP such that $\MDP\models\BMDP_s$. Since $Act^{\BMDP_s}=\{\alpha\}$, we have $Act^\MDP=\{\alpha\}$. We construct a DTMC $\MC=(S^\MC,\PF^\MC,s_0^\MC)$ by defining $S^\MC=S^\MDP=S^\IMC$, $\PF^\MC(s_i,s_j)=\PF^\MDP(s_i,\alpha,s_j)$ for all $s_i,s_j \in S^\MDP$, and choosing $s_0^\MC = s_0^\MDP$.

Since $\MDP\models\BMDP_s$, it follows that
\[
\PFlower^\IMC(s_i,s_j)=\PFlower^{\BMDP_s}(s_i,\alpha,s_j)\leq\PF^\MDP(s_i,\alpha,s_j)\leq\PFupper^{\BMDP_s}(s_i,\alpha,s_j)=\PFupper^\IMC(s_i,s_j).
\]
Hence, $\PF^\MC(s_i,s_j)\in[\PFlower^\IMC(s_i,s_j),\PFupper^\IMC(s_i,s_j)]$ for all $s_i,s_j\in S^\IMC$. Together with the fixed initial state $s_0$, we can thus conclude that $\MC\models_U\IMC$.

It remains to show that the induced probability measures correspond. Let $\pi=(s_0,s_1,\dots,s_n)\in Paths^\MC_{fin}$ be a finite path of $\MC$. Since $\MDP$ has exactly one action, $\pi$ corresponds to the MDP path $\hat{\pi}=(s_0,\alpha,s_1,\alpha,\dots,\alpha,s_n) \in Paths^\MDP_{fin}$. This correspondence is a bijection between the paths of $\MC$ and the paths of $\MDP$. For every finite path $\pi = (s_0,s_1,\dots,s_n) \in Paths^\MC_{fin}$, the corresponding cylinder probabilities are
\[
Pr^\MC(\pi)=\llbracket \pi[0] = s_0^\MC\rrbracket \cdot \prod_{k=0}^{n-1}\PF^\MC(\pi[k],\pi[k+1])
\]
and
\[
Pr^\MDP(\hat{\pi})=\llbracket \pi[0] = s_0^\MDP\rrbracket \cdot\prod_{k=0}^{n-1}\PF^\MDP(\pi[k],\alpha,\pi[k+1]).
\]
By construction, $s_0^\MC = s_0^\MDP$ and $\PF^\MC(s_i,s_j)=\PF^\MDP(s_i,\alpha,s_j)$. Consequently, $\Pr^\MC(\pi)=\Pr^\MDP(\hat{\pi})$ for every finite path $\pi$. Hence, the corresponding cylinder sets have the same probability. Since cylinder sets generate the respective path-space $\sigma$-algebras, the probability measures induced by $\MC$ and $\MDP$ correspond under the above path mapping.
\end{proof}

Notice, that the reward function $rew^\MDP$ of all MDPs $\MDP \models \BMDP$ is precisely the reward function defined in \Cref{lem:from-expected-rewards-to-evts} with $x = 1$. From \Cref{lem:correspondance-between-satisfying-dtmcs-and-mdps}, we can conclude that there exists a corresponding DTMC $\MC \models \IMC$ for each $\MDP$, such that $\Exp^\MDP[tr_{rew}] = \Exp^\MDP[tr_{rew}]$, as their probability measures coincide. Thus, 
\[\Exp^\MC[vt_s] = \Exp^\MDP[tr_{rew}]\ .\]
Therefore, we can calculate the $\ell$EVT and uEVT of $s\in \IMC$ under the UMC semantic by finding the minimum and maximum expected total reward for the BMDP $\BMDP_s$.
